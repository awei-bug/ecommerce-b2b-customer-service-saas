# 电脑端商城（mall）

> 这是给 **顾客在电脑浏览器** 上用的前台，不是手机 App，也不是管理员后台。

## 和后台的分工

| 项目 | 谁用 | 怎么用 |
|------|------|--------|
| **vue_shop** | 店长/管理员 | 电脑后台：上架、发货 |
| **mall** | 顾客 | **电脑浏览器购物站**：逛店、下单 |

## 用户在电脑上做什么

```text
打开商城首页（宽屏商品网格）
  → 点商品进详情
  → 登录（如未登录）
  → 确认地址与金额
  → 模拟支付
  → 在「我的订单」查看
```

## 启动（电脑本机）

```bash
# 1. 后端
cd flask_shop
python manager.py

# 2. 前台商城
cd mall
npm install   # 首次
npm run dev
```

浏览器打开终端提示的地址，例如：

- 商城前台：`http://localhost:5173` 或 `http://localhost:8080`（以终端为准）
- 管理后台：vue_shop 另开端口

登录演示：手机号任意合法号 + 验证码 **`123456`**

进店可带租户：`http://localhost:xxxx/?tenant=demo-a`

## 布局说明（已改为电脑）

- 顶部导航：首页 / 我的订单 / 登录
- 首页：多列商品网格（约 4 列）
- 详情：左图右文
- 确认订单：左表单 + 右侧金额汇总
- 订单：表格列表（适合鼠标操作）

不再使用手机底栏 + 480px 窄屏壳。

## 仍是演示级

- 支付为模拟支付
- 验证码为开发固定码
