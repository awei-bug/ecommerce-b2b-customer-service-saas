# 安晋捷运风格后台 — 图片替换清单

后台里所有 `img-slot` 虚线框都是**占位**，请按下面准备素材后替换。

| 位置 | 建议尺寸 | 格式 | 说明 |
|------|----------|------|------|
| 侧栏左上 **品牌 Logo** | 72×72 或 128×128 | PNG 透明底 | 安晋捷运 / ASKIN 标志；可参考名片上的 ASK+H 图标 |
| 顶栏右上 **用户头像** | 72×72 圆形裁切 | PNG/JPG | 默认头像或用户真实头像 |
| 控制台欢迎区 **欢迎图** | 96×96 | PNG | 品牌吉祥物或简洁插画 |
| KPI 卡片 ×4 图标 | 96×96 | PNG/SVG | 待报价、运输中、待对账、已完成（线性风格更贴截图） |
| 运单轨迹区 **地图背景（可选）** | 约 1600×400 | PNG 半透明 | 浅蓝世界地图底纹，不抢内容 |

### 建议存放路径

```text
vue_shop/src/assets/askin/
  logo.png
  avatar-default.png
  icon-welcome.png
  icon-quote.png
  icon-transit.png
  icon-bill.png
  icon-done.png
  map-bg.png
```

替换时：把对应 `div.img-slot` 改成 `<img src="@/assets/askin/xxx.png" alt="" />` 即可。

### 后端接口（已提供）

| 接口 | 用途 |
|------|------|
| `GET /logistics/dashboard/` | 控制台 KPI + 时间线 + 最近运单 |
| `POST /logistics/inquiries/` | 新建询价 |
| `GET /logistics/invoices/` | 对账列表 |
| `GET/POST /logistics/warehouse/` | 海外仓库存 |
| `GET /logistics/profile/` | 品牌/账号信息 |
