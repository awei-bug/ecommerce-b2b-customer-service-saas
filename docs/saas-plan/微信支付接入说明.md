
# 微信支付（直连商户 · API v3）接入说明

> 代码已接入 `wechatpayv3` 统一下单 + 回调验签解密 + 主动查单。
> **密钥只放本机 `.env` / 服务器环境变量，不要提交 git、不要发到聊天。**

---

## 1. 能力清单

| 能力     | 接口                                      | 说明                                      |
| -------- | ----------------------------------------- | ----------------------------------------- |
| 配置探测 | `GET /pay/channel/status/`              | 不回传密钥                                |
| 创建支付 | `POST /pay/create/` `channel=wechat`  | 返回`code_url` / `h5_url` / `jsapi` |
| 支付回调 | `POST /pay/wechat/notify/`              | 微信服务器调用，验签+解密                 |
| 主动查单 | `GET /pay/wechat/query/<out_trade_no>/` | 本地未更新时补偿                          |
| 模拟支付 | `POST /pay/mock/notify/`                | 仅`ALLOW_MOCK_PAY=1`                    |

成功后：`t_payments.status=success`，订单状态机 → `paid`。

---

## 2. 安装依赖

```bash
cd flask_shop
pip install wechatpayv3==1.2.53 cryptography requests
# 或
pip install -r requirements.txt
```

---

## 3. 准备商户材料

在 [微信支付商户平台](https://pay.weixin.qq.com/)：

1. 商户号 `mch_id`
2. AppID（公众号 / 小程序 / 开放平台，与产品一致）
3. APIv3 密钥（32 位）
4. API 证书：下载后得到 `apiclient_key.pem` + 证书序列号
5. **公网 HTTPS** 回调地址（本地可用内网穿透）

私钥建议放在仓库外：

```text
F:/secrets/wechat/apiclient_key.pem
```

---

## 4. `.env` 配置示例

```env
PAY_DEFAULT_CHANNEL=wechat
ALLOW_MOCK_PAY=0

WECHAT_MCH_ID=190000****
WECHAT_MCH_SERIAL_NO=证书序列号
WECHAT_MCH_PRIVATE_KEY_PATH=F:/secrets/wechat/apiclient_key.pem
WECHAT_APP_ID=wx********
WECHAT_API_V3_KEY=32位APIv3密钥
WECHAT_NOTIFY_URL=https://你的域名/pay/wechat/notify/
WECHAT_PAY_TRADE_TYPE=native
WECHAT_CERT_DIR=F:/secrets/wechat/certs
# JSAPI 时还需要用户 openid：
# WECHAT_PAYER_OPENID=
```

本地开发可继续用 mock：

```env
PAY_DEFAULT_CHANNEL=mock
ALLOW_MOCK_PAY=1
```

---

## 5. 交易类型

| `WECHAT_PAY_TRADE_TYPE` | 场景                  | 返回                              |
| ------------------------- | --------------------- | --------------------------------- |
| `native`                | PC 扫码（推荐先打通） | `client_payload.code_url`       |
| `h5`                    | 手机浏览器            | `client_payload.h5_url`         |
| `jsapi`                 | 微信内公众号          | `client_payload.jsapi` 调起参数 |
| `miniprogram`           | 小程序                | 同 JSAPI，需 openid               |

---

## 6. 调用示例（Native）

```http
POST /pay/create/
Header: token: <商户JWT>
{
  "order_id": 12,
  "channel": "wechat"
}
```

成功时 `prepay.client_payload.code_url` 生成二维码，用户微信扫码支付。
微信回调 → 本地订单变 `paid`。
若回调丢失，可：

```http
GET /pay/wechat/query/P1xxxx/
Header: token: <商户JWT>
```

---

## 7. 前端展示建议

- **Native**：用 `code_url` 生成二维码（如 qrcode.js）
- **H5**：`window.location = h5_url`
- **JSAPI**：`wx.chooseWXPay` / `WeixinJSBridge` 使用 `jsapi` 字段

商城侧可将 `channel` 从 `mock` 改为 `wechat`（配置齐全后）。

## 9. 常见问题

| 现象                    | 处理                                        |
| ----------------------- | ------------------------------------------- |
| `wechat_unconfigured` | 检查 missing 列表与 pem 路径                |
| `未安装 wechatpayv3`  | `pip install wechatpayv3`                 |
| 回调一直失败            | 查服务器时间、APIv3 密钥、证书序列号        |
| JSAPI 报 openid         | 传`openid` 或配 `WECHAT_PAYER_OPENID`   |
| 本地无公网              | 用 ngrok/cpolar 暴露`/pay/wechat/notify/` |
